# Runmesh contributors

Runmesh recognizes contributors through Git history, pull requests, release
notes where appropriate, and any attribution required by an accepted
contribution. Contributor identity is not removed or reassigned merely because
a contribution is relicensed or included in another Runmesh distribution.

## How recognition works

- Git authorship and commit metadata remain the primary technical record.
- Pull requests, issues, documentation, testing, design review, and community
  support are all valued forms of contribution.
- Maintainers may add an individual or organization to release acknowledgements
  with the contributor's consent.
- Do not add private names, employer information, contact details, or legal
  identities here without permission.

## Contributor agreements

For substantive code intended for merge, complete the applicable
[Individual CLA](CLA-INDIVIDUAL.md) or [Entity CLA](CLA-ENTITY.md). The CLA is
an inbound license grant; it does not transfer copyright away from the
contributor. See [CONTRIBUTING.md](CONTRIBUTING.md) and
[docs/cla-setup.md](docs/cla-setup.md).

This page begins with no manually curated list so that it does not make claims
about consent or identity beyond repository evidence. Maintainers may add a
consent-based acknowledgement section as contributions are accepted.
