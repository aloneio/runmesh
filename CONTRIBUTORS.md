# Contributor directory

Runmesh welcomes contributions and keeps copyright and attribution with each
contributor. Ordinary contributions use the deemed-acceptance terms in
[CONTRIBUTION_PERMISSION.md](CONTRIBUTION_PERMISSION.md) sets the default
contribution terms. Git history, merged pull requests, and release notes provide
attribution for accepted contributions. This page is not a record of private
agreements. Contributors may request attribution
corrections through a pull request or maintainer contact.
