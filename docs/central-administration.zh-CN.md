# 管理 MCP 和 Skill

[English](central-administration.md) · [文档目录](README.zh-CN.md)

在控制台的「MCP 和 Skill」页面连接 MCP、安装 Skill，再把共享内容提供给 AI 客户端。

## 三步开始

1. **连接 MCP。** 打开「MCP」，填写服务提供方给你的地址，选择「无身份验证」或 OAuth，然后完成连接或登录。
2. **安装 Skill。** 选择包含 `SKILL.md` 的文件夹，或选择 `SKILL.md` 和配套文本文件，点击「安装 Skill」。
3. **连接 AI 客户端。** 选择「连接 AI 客户端」，填写便于识别的名称，选择访问范围并创建连接。把页面显示的地址复制到 AI 客户端的 MCP 设置中。

已启用的 MCP 工具和 Skill 会提供给该实例中有效的 AI 客户端。安装或更新后，如果客户端仍显示旧内容，请刷新 Runmesh 连接。

## 选择访问范围

- **MCP 和 Skill：** 只能使用实例中共享的 MCP 和 Skill。
- **MCP、Skill 和计算机访问：** 在此基础上，还能使用已授权 Runner 工作区中的文件和命令。

计算机访问的权限在创建连接时选择。需要先在「Runner」页面添加机器，再为它设置允许使用的工作区。[管理员指南](admin-guide.zh-CN.md)介绍添加机器和配置工作区的步骤。

## 日常管理

| 操作 | 结果 |
| --- | --- |
| MCP「刷新工具」 | 读取服务方的最新工具并更新共享列表。 |
| MCP「暂停」/「启用」 | 暂停或恢复该 MCP 的共享。启用时会重新读取工具。 |
| OAuth「重新授权」 | 重新打开服务方登录页面。 |
| OAuth「断开账号连接」 | 移除保存的账号连接；需要时可重新授权。 |
| Skill 上传更新 | 先查看变化，再确认「更新 Skill」；更新会对所有客户端生效。 |
| Skill「暂停」/「启用」 | 暂停或恢复 Skill 的读取，已安装内容会保留。 |

Skill 的显示名称可以在中央列表中修改。重命名后刷新页面仍会保留该名称；删除后不会自动恢复，也不能用原来的 Skill ID 创建新的内容。

## 管理 AI 客户端连接

在「AI 连接」页面：

- **轮换**会生成新地址并立即让旧地址失效；
- **撤销**会停止访问，但保留连接记录；
- **删除**会移除连接记录。

地址和 Runner 注册命令都属于凭据，只通过安全渠道交给指定使用者。发现泄露时立即轮换或撤销。

更多操作见[用户指南](user-guide.zh-CN.md)、[MCP 账号授权](central-oauth.zh-CN.md)、[Skill 安装与更新](central-skills.zh-CN.md)和[故障排查](troubleshooting.zh-CN.md)。部署与版本信息见[发行状态](release-readiness.zh-CN.md)。
