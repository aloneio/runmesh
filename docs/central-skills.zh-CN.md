# 安装与更新 Skill

[English](central-skills.md) · [MCP 和 Skill 指南](central-administration.zh-CN.md)

安装一份 Skill 的说明与配套文本文件，已连接的 AI 客户端即可使用。

## 准备文件

把 `SKILL.md` 放在所选文件夹根目录，参考资料等文本文件放在该目录内：

```text
project-review/
  SKILL.md
  references/
    checklist.md
```

`SKILL.md` 开头用 YAML 元数据提供名称和说明，说明可以分多行编写：

```markdown
---
name: project-review
description: >-
  按项目检查清单进行审查，
  并报告可执行的改进项。
---

阅读 references/checklist.md，检查项目并汇总发现。
```

名称使用小写字母、数字和内部连字符，最多 64 个 UTF-8 字节。所有文件保存为 UTF-8 文本。下载得到压缩包时，先解压，再选择包含 `SKILL.md` 的 Skill 文件夹。选择文件夹会保留子目录结构，单独选择的文件放在根目录。

## 安装

1. 打开「MCP 和 Skill → Skill」。
2. 通过「Skill 文件夹」选择整个目录，或通过「Skill 文件」选择 `SKILL.md` 与配套文件。
3. 点击「安装 Skill」。
4. 在已安装卡片上点击「查看文件」，核对内容。

Skill 随即向实例中的所有有效 AI 客户端开放。在客户端刷新 Runmesh 工具或资源列表，再用 `skill_list` 查找，用 `skill_read` 读取正文与附件。提供 MCP 资源浏览功能的客户端也可从资源列表打开 Skill。

读取 `SKILL.md` 时还会返回文件清单，包含各文件的路径、UTF-8 字节数和 SHA-256 摘要。按清单中的路径，使用同一 Skill 摘要读取所需附件。

Skill 文件以文本交付。AI 客户端根据说明使用可用工具，每个工具按各自权限执行。共享前请核对 Skill 的来源和内容。

## 从 GitHub 导入

在 Skill 区域展开「从 GitHub 导入」，填写公开仓库地址、完整的 40 位提交 SHA，以及 Skill 文件夹路径。`SKILL.md` 位于仓库根目录时，路径留空。点击「预览 Skill」，核对文件后点击「安装 Skill」或「更新 Skill」。

安装后的来源链接指向该次提交。后续更新时，填写新的提交 SHA 并重新预览。每次导入最多包含 32 个文本文件；文件较多时可使用文件夹上传。

## 更新、暂停与恢复

更新时保持 `SKILL.md` 中的 `name` 相同，选择更新后的文件夹或文件，点击「安装 Skill」，核对展示的文件后点击「更新 Skill」。新版本会对所有客户端生效。

「暂停」停止后续读取并保留当前选用版本。点击「查看文件 → 启用 Skill」即可恢复该版本。已经读入对话的内容仍留在该对话中；任务需要全程使用新版本时，可开启新对话。

卡片说明和「查看文件」展示当前选用版本，包括从版本记录中恢复的版本。最近上传的版本与它不同时，可点击「查看最近上传」，核对后点击「更新 Skill」使其生效；暂停状态下，该操作显示为「启用 Skill」。

更新后，客户端重新调用 `skill_list`，使用返回的新摘要读取 `SKILL.md` 和所有附件，使任务始终使用同一版本的内容。

## 管理版本和容量

在 Skill 卡片上点击「版本记录」，查看保留的版本、文件数、大小及 Skill 库容量。每个版本以内容摘要标识；已记录安装时间的版本还会显示相应时间。

- 选择两个版本并点击「比较版本」，查看文件和元数据的变化。打开对应版本的文件可阅读全文。
- 点击「使用此版本」并确认，即可让所有客户端使用该历史版本。
- 点击「保留版本」，将版本留待后用；「取消保留」可解除这一选择。
- 勾选旧版本，点击「预览清理」，核对版本列表和释放空间后确认。使用中的版本、最近上传的版本和已保留版本会留在库中。

清理预览有效期为五分钟。更改选择或更新 Skill 后，重新预览即可继续。清理完成后，页面会更新容量，此时可安装下一版本。

## 文件与存储上限

| 项目 | 上限 |
| --- | --- |
| 每个上传 Skill 的文件数 | 256 个 |
| 每次 GitHub 导入的文件数 | 32 个 |
| 单文件大小 | 1 MiB |
| 文件路径长度 | 200 个字符 |
| 上传包，含编码后的路径与元数据 | 8 MiB |
| 每个 Skill 保留的版本数 | 32 个 |
| 每个实例的 Skill 数 | 1,000 个 |
| 每个实例的 Skill 内容总存储 | 256 MiB |

文件大小按 UTF-8 字节计算。存储容量统计已保留版本的逻辑大小，包含 JSON 编码、路径和元数据；Cloudflare 的存储与计费用量可在其控制台查看。再次安装相同内容会沿用已有版本及其记录时间。

所选目录保留 Skill 说明和相关参考资料，将依赖目录、构建产物与无关文件移出。文件使用正斜杠分隔的相对路径，名称由英文字母、数字、点、下划线和连字符组成，例如 `references/checklist.md`。名称应符合 Windows 文件命名规则，完整文件路径在忽略大小写后也应各不相同。达到版本或存储上限时，打开「版本记录」清理旧版本即可。

上传内容需要调整时，按页面提示修正文件，重新选择并提交。常见上传与更新问题见[故障排查](troubleshooting.zh-CN.md)。

API 分页、可选依赖元数据和版本管理见[Skill 参考](maintainers/central-skills.zh-CN.md)。
