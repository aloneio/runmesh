# 安装与更新 Skill

[English](central-skills.md) · [MCP 和 Skill 指南](central-administration.zh-CN.md)

Skill 是一组给 AI 使用的说明和参考资料。安装后，该实例中有效的 AI 客户端都可以使用它。

## 准备文件

把 `SKILL.md` 放在 Skill 文件夹的根目录，参考资料放在下面的子目录中：

```text
project-review/
  SKILL.md
  references/
    checklist.md
```

`SKILL.md` 开头需要有名称和说明。名称使用小写字母、数字和连字符，最长 64 个字节。所有文件都应是 UTF-8 文本。下载压缩包时先解压，再选择包含 `SKILL.md` 的文件夹。

## 安装

1. 打开「MCP 和 Skill → Skill」。
2. 选择整个 Skill 文件夹，或选择 `SKILL.md` 和配套文本文件。
3. 点击「安装 Skill」，再打开「查看文件」确认内容。

安装后，在 AI 客户端刷新 Runmesh 连接即可使用。共享前请确认 Skill 的来源和内容。

## 从 GitHub 导入

展开「从 GitHub 导入」，填写公开仓库地址、要使用的提交版本和 Skill 文件夹路径。若 `SKILL.md` 在仓库根目录，路径留空。先点击「预览 Skill」，确认文件后再安装或更新。

导入内容来自你选择的提交版本。要更新时选择新的提交版本并再次预览。导入文件过多或单个文件过大时，页面会提示你缩小范围；此时可以改用文件夹上传。

## 更新、重命名、暂停和删除

- **更新：** 选择新的文件，确认预览后点击「更新 Skill」。更新会对所有客户端生效。
- **重命名：** 在中央列表修改显示名称。显示名称只影响你和用户看到的标题，不会改变 Skill 的原始身份；刷新页面后名称仍会保留。
- **暂停：** 暂停后客户端不能继续读取，但当前内容会保留。选择「启用」即可恢复。
- **删除：** 删除会移除 Skill 的可用内容并保留删除记录。原来的 Skill ID 永久不能复用，旧上传内容也不会因为刷新或重新导入而自动恢复。

已经读入对话的内容会留在原对话中；需要完整使用新版本时，请开启新对话。

## 版本记录和容量

打开 Skill 卡片的「版本记录」可以查看历史版本、比较变化、恢复某个版本或清理旧版本。清理前先预览，确认后再执行；当前使用中的版本和保留版本不会被清理。

单个 Skill 最多保留 32 个版本；每个实例最多 1,000 个 Skill，总存储上限为 256 MiB。单文件上限为 4 MiB，一次 GitHub 导入最多 32 个文本文件。达到上限时，清理不再使用的旧版本后再安装。

如果上传失败，请按页面提示修正文件并重新选择；常见问题见[故障排查](troubleshooting.zh-CN.md)。
