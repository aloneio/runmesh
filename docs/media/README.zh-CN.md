## 视频内容

| 时间 | 内容 |
| --- | --- |
| 00–06 | 让 AI 通过 Runmesh 用上你自己的机器。 |
| 06–18 | 一个入口访问 Linux、macOS 和 Windows。客户端使用独立凭据，机器密钥保留在机器连接侧。 |
| 18–31 | Runner 主动向 Runmesh 建立连接，让 NAT 内网中的机器接收远程任务，无需公网 IP。 |
| 31–44 | 在 Runmesh 配置 MCP 和 Skill。换个 AI 客户端，同一套工具与项目规范继续使用。 |
| 44–53 | 查资料、读项目、跑测试，串起一次完整任务。 |
| 53–60 | 你的机器，你的工具，一个入口。 |
