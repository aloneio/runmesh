## 0.1.7 — 已发布正式版

[Runmesh 0.1.7](https://github.com/aloneio/runmesh/releases/tag/v0.1.7) 已发布，提供签名便携 Runner 安装包。安装与升级步骤见[发行状态](release-readiness.zh-CN.md)。

### Runner 服务

- Linux 用户级服务通过当前账号的本地服务管理器完成安装、状态检查、停止、重启和卸载。
- Linux、macOS 和 Windows 的用户级服务均以用户模式启动。更新已有服务时，会修正启动设置并保留自定义程序路径和参数。

### MCP 连接与稳定性

- 控制端短暂不可用时保留现有 OAuth 连接；账号需要重新登录时再打开授权页面。
- Runner 断开连接或遇到控制端暂时故障时，会及时释放无需继续读取的响应资源。

### 控制端

- 客户端列表的凭据状态更简洁，日期与 UTC 时间分行显示，可查看完整时间戳。

### 安全更新

- Hono 更新至 4.13.7，修复 JSX 渲染中的 GHSA-hxh3-vqpv-xpqv 漏洞。

### 升级

按[升级指南](upgrading.zh-CN.md)更新控制端和 Runner。用户级服务更新程序后，使用原配置执行 `install --user`，应用新的启动设置。现有账号连接、Runner 配置及工作区设置继续沿用。

## 0.1.6 — 已发布正式版

[Runmesh 0.1.6](https://github.com/aloneio/runmesh/releases/tag/v0.1.6) 已发布，提供签名便携 Runner 安装包。更新已有实例至当前版本时，按[升级指南](upgrading.zh-CN.md)操作。

### MCP 和 Skill

- 填写 MCP 地址，选择无身份验证或 OAuth 即可连接。登录授权后返回控制端，自动加载工具。
- 点击「重新授权」可直接开始新的提供方登录流程；刷新工具时需要登录，也会自动进入授权。
- 选择 Skill 文件夹，或 SKILL.md 与配套文本文件即可安装；同名更新经确认后对所有已连接客户端生效。
- AI 连接可直接使用共享 MCP 工具和 Skill。需要 Runner 文件与命令工具时，选择计算机访问，页面自动展开权限选项。

### 日常使用与稳定性

- 控制台链接会定位到页头下方的对应内容，打开新页面时从标题开始显示。长短页面切换时，页面高度随内容调整。快速导航时，浏览器地址与显示页面保持一致；请求停滞 25 秒后，重新加载最后选择的页面。
- Runner 安装页在窄屏上布局更紧凑；调整窗口大小后，命令区域重新适应内容，清除尺寸变化造成的多余空白。
- Runner 详情会显示工作区设置正在应用的状态；查询停滞时，在限定等待后给出结果。
- 开发版下载与 Runner 页面显示同一已验证版本。并发下载共享校验结果，刷新失败时可恢复仍有效的已验证发行物。
- Git 检查更准确地识别工作区中的并发修改，并在启动命令前发现无效的超时设置。
- 中英文指南按 MCP/Skill 与计算机访问分别提供流程，补齐 OAuth、Skill 更新及版本选择的直接操作说明。

### 升级

Runmesh 0.1.6 加入共享 MCP 连接和 Skill。升级时保留现有部署密钥，使已连接 OAuth 账号继续使用原有凭据。按[升级指南](upgrading.zh-CN.md)部署经过审核的发行激活版本、安装签名 Runner 包并刷新客户端目录。

正式版本验证并激活后，后续开发批次采用下一补丁版本系列。安装页提供当前已验证且协议兼容的开发包。

## 0.1.5 — 已发布正式版

于 **2026 年 9 月 23 日**发布为[不可变正式版](https://github.com/aloneio/runmesh/releases/tag/v0.1.5)，提供已签名的便携 Runner 安装包。该版本来自受保护 main 提交 `77e82a1b59737a42cc090064651d1b0531890f21`；独立核验的 manifest SHA256 为 `34da9baefabddd882aeef79151b132b1de4086fce54de7a46fe853a7e8dac18a`。

该版本修复 Windows 安装：在本地化 Windows 主机上，缺失的 `RunmeshRunner` 任务现在通过与语言无关的 COM 接口识别。遇到权限或任务计划程序错误时，安装会停止并报告原因，便于管理员处理。

更新已有安装时，请按[升级指南](upgrading.zh-CN.md)操作，以保留现有凭据和配置。

## 0.1.4 — 已发布正式版

于 **2026 年 9 月 20 日**发布为[不可变正式版](https://github.com/aloneio/runmesh/releases/tag/v0.1.4)，提供已签名的便携 Runner 安装包。

**0.1.4** 改进了任务控制、MCP 恢复、工作区 Context 管理和安装流程。已验证安装包的可用情况及托管安装状态见[发行状态](release-readiness.zh-CN.md)；更新 Worker、Runner 和客户端时，请按[升级指南](upgrading.zh-CN.md)操作。

### 升级兼容组件后可获得的改进

- **更可靠的任务控制。** 取消后状态仍不确定的存活进程会继续受到跟踪，直到确认其状态。并发恢复遵循已有取消送达记录。输入错误会给出恢复指引，便于先检查原进程再决定后续输入。
- **更明确的 Linux 恢复结果。** Runner 重启后，进程已退出的未完成任务会被确认为中断；有相应取消送达记录时，任务会确认为已取消。
- **更清晰的 MCP 调用与恢复。** 按动作区分的工具定义、工作区绑定查询和结构化错误，帮助在故障后跟踪原任务。云端历史不可用时，可用原 Job ID 和工作区 ID 查询在线 Runner。
- **更方便地管理 Context 和读取分页内容。** 查看 Context 存储用量并清理选定的旧版本。可选的快照读取让文件各页来自同一份已捕获内容，追加读取则跟进同一代次的 Job 日志。使用前可通过 Runner 诊断查看支持情况。
- **减少空闲历史上传。** 兼容的 Worker/Runner 组合在已记录任务发生变化时上传元数据，收到确认后停止历史计时器。普通日志按需读取，连接心跳、授权和维护继续使用账号资源。
- **更严格的本地与分发校验。** 元数据和发布输入增加对特殊文件替换的检查，发布前健康检查会识别超大或停滞的响应。已发布包保留原有身份，正式标签发布流程显式核对项目标签作者。
- **更可靠的安装与混合版本运行。** 托管安装器将安装、凭据刷新和卸载串行执行，失败时仅清理自己创建的路径。Windows 发布下载的超时覆盖响应正文；修复 macOS 专用服务组名和 Windows 目录创建。MCP Runner 选择在写入前核对原始凭据，任务元数据拒绝读取中发生的替换或改写。
- **同步用户文档。** 中英文指南区分首次安装、兼容升级、任务恢复、正式发行与开发测试；旧迁移和审计记录与日常使用说明分开。

### 升级注意事项

按[升级指南](upgrading.zh-CN.md)依次部署兼容 Worker、安装目标 Runner 包、刷新客户端工具目录。保留既有 v2 资源和凭据，并验证 `shell` 回执与同一任务的后续查询后，再恢复日常工作。

Context 存储统计和清理需要 Runner 在已认证的握手中声明对应能力。收到 `runner_upgrade_required` 时，核对已安装版本，升级后重新连接；原连接仍可使用已有能力。Worker 升级前休眠的连接也可能需要重新握手。

### 使用建议

命令使用 Runner 服务账号的系统权限，运行不受信任的代码时应使用容器或虚拟机。需要长期保留的输出请及时导出。恢复后标记为 `unknown` 的任务需要进一步检查；取消后确认最终任务状态，再安排替代任务。
