# Runmesh 0.1.10

## Cancellation handling

Runner maintenance and release downloads now keep cancellation consistent through the final stage of a response. An interrupted update keeps its interrupted result and can be retried safely with the same installation.

Follow the [upgrade guide](https://github.com/aloneio/runmesh/blob/main/docs/upgrading.md) to update the control plane and Runner. Existing installation settings and credentials continue to be used.

## 简体中文

### 取消处理

Runner 维护和发行物下载会在响应即将结束时继续保持取消状态。中断更新会保留清晰的中断结果，并可在同一安装上安全重试。

按[升级指南](https://github.com/aloneio/runmesh/blob/main/docs/upgrading.zh-CN.md)更新控制端和 Runner；现有安装设置和凭据会继续沿用。
