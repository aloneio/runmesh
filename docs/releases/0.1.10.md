# Runmesh 0.1.10

## Status

0.1.10 is being prepared. The published 0.1.9 package remains the stable release until 0.1.10 is available.

## Cancellation handling

Runner maintenance and release downloads now keep cancellation consistent through the final stage of a response. An interrupted update keeps its interrupted result and can be retried safely with the same installation.

Use the standard [upgrade guide](https://github.com/aloneio/runmesh/blob/main/docs/upgrading.md) after 0.1.10 becomes available. Existing installation settings and credentials continue to be used.

## 简体中文

### 状态

0.1.10 正在准备。已发布的 0.1.9 是当前稳定版本，0.1.10 正式发布后再提供给稳定安装。

### 取消处理

Runner 维护和发行物下载会在响应即将结束时继续保持取消状态。中断更新会保留清晰的中断结果，并可在同一安装上安全重试。

0.1.10 正式发布后，请按[升级指南](https://github.com/aloneio/runmesh/blob/main/docs/upgrading.zh-CN.md)操作；现有安装设置和凭据会继续沿用。
