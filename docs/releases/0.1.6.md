# Runmesh 0.1.6

## English

Connect MCPs and install Skills directly from the control panel, then use them from your AI clients.

### MCP and Skill

- Connect an MCP by entering its URL and choosing no authentication or OAuth. Account authorization returns to the panel and loads the available tools automatically.
- Use **Reconnect** to start a fresh sign-in. Refreshing tools also opens authorization when the account needs it.
- Install a Skill folder or `SKILL.md` with its supporting text files. Review same-name updates and make the new content available to all connected clients.
- Choose **MCP, Skills and computer access** to add Runner file and command tools. The panel opens the computer permission choices automatically.

### Everyday improvements

- Clearer English and Chinese setup guides, responsive forms and more consistent console navigation.
- Revoked AI connections return a clear error promptly, including in clients with a cached tool catalog.
- Runner details show workspace settings being applied and give feedback when a query takes too long.
- Development downloads and Runner pages use the same verified version. Concurrent downloads share verification, and refresh failures can recover a valid cached release.
- Git checks handle concurrent workspace changes more consistently and validate command timeouts before execution.

### Upgrade

Follow the [upgrade guide](https://github.com/aloneio/runmesh/blob/main/docs/upgrading.md) to update the Worker, Runner package and client tool catalog. Retain existing resource identities, Runner credentials, workspace settings and deployment secrets so connected accounts keep their configuration.

The [release status](https://github.com/aloneio/runmesh/blob/main/docs/release-readiness.md) records production availability. New Runner installations start from the control panel's enrollment page.

## 简体中文

在控制端直接连接 MCP、安装 Skill，即可通过 AI 客户端使用。

### MCP 和 Skill

- 填写 MCP 地址，选择无身份验证或 OAuth 即可连接。账号授权后自动返回控制端并加载工具。
- 点击「重新授权」可开始新的登录流程；刷新工具时需要登录，也会自动进入授权。
- 选择 Skill 文件夹，或 `SKILL.md` 与配套文本文件即可安装；同名更新经确认后对所有已连接客户端生效。
- 选择「MCP、Skill 和计算机访问」即可添加 Runner 文件与命令工具，页面会自动展开计算机权限选项。

### 日常体验改进

- 完善中英文使用指南、不同屏幕尺寸下的表单布局和控制台导航。
- 撤销 AI 连接后，即使客户端已缓存工具目录，也能及时收到明确的错误反馈。
- Runner 详情显示工作区设置的应用进度，并在查询耗时过长时给出反馈。
- 开发版下载与 Runner 页面使用同一已验证版本；并发下载共享校验，刷新失败时可恢复有效的缓存发行物。
- Git 检查更准确地处理工作区中的并发修改，并在执行命令前校验超时设置。

### 升级

按[升级指南](https://github.com/aloneio/runmesh/blob/main/docs/upgrading.zh-CN.md)更新 Worker、Runner 安装包和客户端工具目录。保留现有资源标识、Runner 凭据、工作区设置与部署密钥，使已连接账号继续沿用原有配置。

[发行状态](https://github.com/aloneio/runmesh/blob/main/docs/release-readiness.zh-CN.md)记录生产环境的可用情况。新 Runner 从控制端的注册页面开始安装。
