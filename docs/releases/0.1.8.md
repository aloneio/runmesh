# Runmesh 0.1.8

## English

### Manage computers and versions

- Select signed Runner releases from the control panel. The independent version manager preserves configuration, waits for running tasks and verifies reconnection after a switch.
- Recover interrupted updates from the local journal and restore the previous package when a switch fails.
- Improved installation, service startup and maintenance recovery across Windows, Linux and macOS.
- Detailed task results preserve Windows process exit codes; completion notifications retain compatibility with existing control planes.

### MCP and Skills

- Inspect MCP connection status and declared capabilities, import remote entries from MCP Registry files, and search published tools across enabled services.
- Import Skills from a public GitHub folder at a fixed commit. Compare, retain and restore saved versions, and preview storage cleanup.
- Upgrade existing Skill libraries with bounded content reads while preserving saved versions and publication state.

### Daily use

- Clearer navigation, Runner actions, client statuses and timestamps, with layouts that adapt to narrow screens.
- Updated English and Chinese setup, upgrade and recovery guides, plus a narrated product overview.

### Upgrade

Follow the [upgrade guide](https://github.com/aloneio/runmesh/blob/main/docs/upgrading.md). Retain your existing Cloudflare resources, deployment secrets, Runner profiles and workspace settings. For remote version management, follow [Runner versions](https://github.com/aloneio/runmesh/blob/main/docs/runner-versions.md) to install the current maintenance component.

## 简体中文

### 管理计算机与版本

- 在控制端选择签名 Runner 版本。独立版本管理器保留配置，等待运行中的任务完成，并在切换后确认重新连接。
- 根据本地日志恢复中断的更新；切换失败时尝试还原原安装包。
- 改进 Windows、Linux 和 macOS 的安装、服务启动及维护恢复流程。
- 详细任务结果保留完整的 Windows 进程退出码；完成通知继续兼容现有控制端。

### MCP 与 Skill

- 查看 MCP 连接状态与声明的能力，从 MCP Registry 文件导入远程条目，跨已启用服务搜索已发布工具。
- 从固定 commit 的公开 GitHub 目录导入 Skill，比较、保留和恢复已保存版本，并预览存储清理结果。
- 已有 Skill 资料库按包读取内容完成升级，保留历史版本与发布状态。

### 日常使用

- 导航、Runner 操作、客户端状态和时间显示更清晰，页面适应窄屏尺寸。
- 更新中英文配置、升级和恢复指南，提供带旁白的产品介绍视频。

### 升级

按[升级指南](https://github.com/aloneio/runmesh/blob/main/docs/upgrading.zh-CN.md)操作，保留现有 Cloudflare 资源、部署密钥、Runner 配置及工作区设置。启用远程版本管理时，按 [Runner 版本管理](https://github.com/aloneio/runmesh/blob/main/docs/runner-versions.zh-CN.md)安装当前维护组件。
