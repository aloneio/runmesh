# Runmesh 0.1.9

## English

### Windows Runner version switches

The 0.1.9 version manager validates the selected release's runtime in its final version directory before switching the active installation. Upgrades and returns to an earlier signed release preserve the Runner's existing configuration.

The new `manager-refresh` command updates an existing independent manager from a verified signed package. It preserves the manager's identity and state, installed Node runtime, Runner profile, workspaces and original service enablement. An interrupted refresh can resume using the same package and command.

### Upgrade

For an existing manager, follow [Update an installed version manager](https://github.com/aloneio/runmesh/blob/main/docs/upgrading.md#update-an-installed-version-manager) first, then choose the desired Runner version in the control panel. New installations and first manager setup receive the manager included in their selected package. The [Runner version-management guide](https://github.com/aloneio/runmesh/blob/main/docs/runner-versions.md) covers everyday operation. Retain your existing Cloudflare resources, deployment secrets, Runner profiles and workspace settings.

## 简体中文

### Windows Runner 版本切换

0.1.9 版本管理器先在最终版本目录校验所选发行包的运行时，再切换当前安装。升级及切回已签名旧版继续保留 Runner 的现有配置。

新增 `manager-refresh` 命令，用已验签发行包更新已有的独立管理器，保留管理器身份与状态、Node 运行时、Runner 配置、工作区及原服务启用状态。更新中断后可使用同一份包和命令继续恢复。

### 升级

已有管理器先按[更新已安装的版本管理器](https://github.com/aloneio/runmesh/blob/main/docs/upgrading.zh-CN.md#更新已安装的版本管理器)操作，再在控制端选择目标 Runner 版本。新安装及首次启用管理器使用所选包自带的管理器。日常操作见 [Runner 版本管理指南](https://github.com/aloneio/runmesh/blob/main/docs/runner-versions.zh-CN.md)。保留现有 Cloudflare 资源、部署密钥、Runner 配置及工作区设置。
