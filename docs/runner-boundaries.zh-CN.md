# Job 与 Context 副作用隔离（AR07）

基线为 `a9b9bb5ef1e7275285c4ccfa54db0c685a03c23e`。本次拆分 Runner 内部职责，不新增工具、执行能力、自动清理、状态迁移或服务升级。

## 模块边界

| 模块 | 职责 |
| --- | --- |
| `jobs.ts` | 保留准入、排队、当前记录／子进程、终态发布、取消和恢复顺序 |
| `jobs/records.ts`、`values.ts` | 原有类型、记录校验、有界启动参数及请求指纹 |
| `jobs/storage.ts` | 私有路径检查、有界元数据读取、原子 JSON 和日志描述符 |
| `jobs/process.ts` | 同步 spawn、进程身份观测、原生终止，不决定业务准入 |
| `jobs/logs.ts` | 通过窄接口读取日志页，不控制进程或修改任务元数据 |
| `jobs/recovery.ts` | 原有恢复记录投影，不探测 PID、不猜测退出码 |
| `context-store.ts` | 保留工作区串行化、检查点提交流程和兼容入口 |
| `context/model.ts`、`storage-types.ts` | 格式、验证、指纹和观察类型，不依赖文件系统或进程 |
| `context/repository.ts`、`files.ts` | 私有路径、有界记录／索引访问、不可变记录和原子索引写入 |
| `context/retention-plan.ts` | 对已验证候选排序、限量、生成哈希与摘要，不访问磁盘或时钟 |
| `context/retention.ts`、`recovery.ts` | 原有逐项删除与显式索引恢复，不自动重放或迁移 |

接口用于进程内协作，不是新的 RPC、部署变量或插件配置。日志读取器仅接收日志访问与范围回调；Context 删除与恢复只接收各自必需的操作，不获取整个 Store 或通用可变上下文。新增对象构造时不访问磁盘、进程或凭据。

JobManager 仍拥有状态转换。持久化链、终态写入保留标记、完成 Promise 和取消送达证据有意放在同一个协调者中，避免为了缩短文件而制造多个状态所有者。入口仍然较大，不宣称本批已消除全部生命周期复杂度。

## 不可移动的时序

spawn 适配器同步调用 Node 原语；同一轮内的策略复查、启动指纹、运行状态发布和监听器安装保留原序。取消的最后身份检查仍紧邻原生终止调用。原有 POSIX 升级信号和 Windows taskkill 超时保持，不新增后台轮询。

Job 终态仍在元数据落盘成功后发布，较晚的 running 快照不能覆盖终态写入。非零退出保留真实退出码，终止未送达不假报取消。重启时无法证明结果的进程仍保持 unknown／interrupted。持久化回执与 OS spawn 不是精确一次事务。

Context 保持“意图 → 不可变记录 → 派生索引 → 清除所属意图”的顺序。只读恢复不建目录、不写入；索引重建显式触发，并校验原记录而非改写。多个 Store 实例共享的进程内串行化保留。

保留计划只接受已校验、符合保留条件的观察结果，不自行授权。执行器按原顺序检查索引、盘点、有界读取、年龄条件与清单哈希，每次删除前核验内容、最新版本、路径和当前权限。最终授权与发起删除之间不增加 await。部分删除失败要求重新预览，不假报整体回滚或安全擦除。

## 验证边界

语法树对照只允许明确的接收者替换与计划函数提取：核对 45 个 JobManager 方法、2 个日志方法、19 个 Context 方法、99 项迁移声明、公共签名、检查点／重建流程、构造顺序及 3 处原有定时器调用点。清单哈希的字段顺序和记录绑定不变。

15 个固定原生文件场景对照未修改基线的返回结果、持久化文件哈希、文件操作顺序与次数。清单哈希含 inode 观察，不同临时目录的该字段合理不同；两边各用自己的准确预览执行，跨目录回执比较仅排除此字段。此项不是生产压力或账户额度验收。

新增测试覆盖无 I/O 构造、rename 失败保留旧文件、临时清理、超大元数据拒绝、空日志与不可用日志、同步 spawn、无身份不取消、unknown 恢复、待恢复意图和纯计划确定性。原有快进程、取消竞态、公平排队、重启、部分删除和真实中断用例继续执行。实际开发测试包还需离线安装、禁用安装脚本后跑 MCP 端到端。

架构门禁阻止内部模块反向导入 facade／连接／服务入口，阻止 model／planner 依赖文件／进程／定时器或具体适配器，阻止 ports 依赖实现，以及日志读取器依赖进程控制或元数据存储。静态检查不是 OS 沙箱，也不保证任意第三方代码安全。

## 资源与交付

不新增持久化文件、状态字段、表、云请求、长期定时器、必填配置或依赖；原有容量、保留期和路径／权限检查不变。纯规划复制一次有界候选数组，并非零内存分配；函数间协作不是远程服务，原有 I/O 仍有开销。

公开方法与类型兼容。Worker、协议目录、Wrangler、发行记录和已发布资产不在修改范围。未签名开发测试包不是正式 v0.1.3 的替换品；生产晋升和签名发版仍需独立授权。本批不重启、重新注册或轮换维护 Runner 凭据。
