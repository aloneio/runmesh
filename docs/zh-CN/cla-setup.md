# 贡献条款与记录说明

Runmesh 对普通社区贡献采用默认视为同意。贡献者不需要签署、发送邮件、上传或私下保存单独的
CLA 或贡献者协议。向官方 `aloneio/runmesh` 仓库提交贡献，即视为你已就该贡献接受
[CONTRIBUTION_PERMISSION.zh-CN.md](../../CONTRIBUTION_PERMISSION.zh-CN.md) 中的条款。

## 贡献者确认事项

提交贡献即表示贡献者确认自己有权提交，并有权授予贡献许可；同时确认已经处理适用的雇主、
承包、保密、依赖和专利义务。雇员或实体代表还确认自己有权作出该许可授权。

贡献许可是非独占、全球、免版税和永久的，包含使用、修改、分发、再许可以及在 Runmesh 社区版和
未来取得商业许可的版本中发布已接收贡献所需的权利。但它不授予 Runmesh 本身的商业使用权。

## Pull request 处理

Pull request 模板中的贡献条款复选框只是通俗提醒，不是签名请求，也不要求保存私密记录。如果
所有权、保密、专利或许可授权不明确，维护者可以要求说明；问题无法解决时，也可以拒绝该贡献。

请在 Git 和项目致谢中保留贡献者署名。不要提交签名、个人地址、身份证明或雇主保密信息。

## 不使用 CLA 自动化

Runmesh 不使用，也不会声称使用 CLA Assistant。此流程不需要外部 CLA 服务、Webhook、账户或私密协议数据库。
